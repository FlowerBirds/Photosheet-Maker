# Photosheet-Maker
图片相纸排版工具，将照片批量排版至六寸、A4等指定相纸，生成排版完成的高清导出图片

### 像素换算公式

```
像素宽度 = 物理宽度(mm) × DPI / 25.4
像素高度 = 物理高度(mm) × DPI / 25.4
```

### 排版说明

- 一寸照：横向版式常用于证件（如身份证），竖向版式常用于简历
- 二寸照：标准为横版（宽 > 高），与一寸相反
- 小二寸：竖版（高 > 宽），与一寸接近但更修长

### 排版计算示例

以 **A4 相纸排一寸照** 为例：

```
A4 可用区域：210mm × 297mm
一寸照尺寸：25mm × 35mm
每行照片数：floor(210 / 25) = 8 张
每列照片数：floor(297 / 35) = 8 张
理论总数：8 × 8 = 64 张

实际建议：考虑 2mm 安全间距后约 24 张（含留白美观）
```

### 排版参数建议

| 参数 | 推荐值 | 说明 |
